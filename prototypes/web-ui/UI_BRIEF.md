# CDC 管理平台 Web UI 提示词

设计一个中文数据库 CDC 管理后台，供 DBA 和运维管理实例与增量同步任务。沿用已选第 2 套的视觉语言：石墨深色背景、青蓝强调、细边框、紧凑但可读的字体和表格；支持浅色。避免渐变、三列卡片、营销式大标题和模板化 SaaS 布局。

固定左侧导航包含：数据库总览、同步任务、添加任务、设置。顶部展示当前页面、全局状态、主题和账号。“添加任务”只在左侧提供入口，首页和任务列表不重复放按钮。

- 登录：账号、密码、错误反馈；未登录进入任意业务地址先显示登录，登录后返回目标页面。正式系统须使用服务端会话，所有页面与 API 均检查权限，前端隐藏内容不能代替鉴权。
- 首页：面向全部已管理实例。主区域为实例表，展示名称、地址、版本、连接、ROW/FULL/GTID、任务角色与关联任务数；右侧查看所选实例完整配置及关联任务。下方以简洁列表展示任务分布，不展示某一条任务的拓扑。实例角色由关联任务计算，同一实例可同时承担源端和目的端。
- 任务列表：每行展示任务、源实例、目的实例、同步范围、状态和延迟。支持搜索、状态筛选和由实例进入的关联筛选。点击任务进入包含任务 ID 的独立详情地址。
- 任务详情：只展示当前任务。上方为源端到目的端的拓扑，左右库表树展示当前任务的映射；选择节点可查看配置，选择表可同时展开两端字段。下方为当前任务的事务日志、运行事件、错误日志，各标签显示对应记录。切换任务时实例、库表、点位和日志一起变化；刷新或返回不能串到其他任务。
- 添加任务：左右选择源、目的实例和库表；同步范围及映射数量明确。逐步补齐同步配置与检查创建流程。
- 设置：当前账号、深浅色、账号管理、日志路径和平台版本。实际删除账号时需保护唯一管理员并确认删除。

先用模拟数据做可交互原型，不接真实数据库。覆盖 5.7→8.4、5.7→8.0、8.0→8.4 三条不同链路，另有未完成配置任务。展示搜索为空、没有错误日志、未知任务和未登录状态。未接入的操作明确提示，不能假装已修改服务端。示例登录 admin / cdc-demo 只用于页面演示。
